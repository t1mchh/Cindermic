## Cindermic v0.3.0

Turn your iPhone into a local wireless microphone for macOS and Windows.

### Downloads

- **Mac Apple Silicon:** `Cindermic-0.3.0-mac-arm64.zip` — extract and move Cindermic.app to Applications.
- **Mac Intel:** `Cindermic-0.3.0-mac-x64.zip`.
- **Windows x64:** `Cindermic-0.3.0-windows-x64.exe` installer, or the ZIP for portable use.
- **SHA256SUMS.txt:** SHA-256 checksums for all four downloads.

### Included

- iPhone QR pairing with manual-link fallback and pinned TLS transport over local Wi-Fi.
- Synchronized mute, automatic reconnect, and the M keyboard shortcut on desktop.
- Reactive mic visuals, a live meter and waveform, and dark/light themes.
- Natural, Voice, and Warm output profiles with a saved selection.
- Local WAV clips up to two minutes, with silence during mute and connection gaps.
- English, German, and Russian UI.

### Connect

Open the desktop app and keep its QR code visible. Put the iPhone and computer on the same Wi-Fi, open the iPhone companion, and scan the desktop code. Allow the requested camera, microphone, and local-network access. For listening, use headphones and enable Audio output.

The iPhone companion requires iOS 17+ and a local Xcode build (`npm ci` then `npm run ios`). There is no App Store or pre-signed iPhone download in this release.

### Validation and current scope

Desktop packages are built on native macOS ARM64, macOS Intel, and Windows x64 runners. The automated suite includes 26 unit/integration tests and a synthetic end-to-end audio test covering capture, playback, mute, reconnect, profiles, and WAV download. Basic iPhone use was reported working by the project owner; long lock-screen sessions, roaming, and interruptions still need systematic hardware tests. Native Windows hardware audio and application routing are not independently device-tested by this release workflow.

Mac builds use an ad-hoc signature and are not notarized. Windows builds do not have a publisher signing certificate. Operating systems may display verification warnings.

For Discord, OBS, and games, install a separate virtual audio device and route Cindermic into it. The app does not install a virtual microphone driver. Bluetooth, Wi-Fi Direct, USB, and Android are not implemented.
